# 壹刻 · 朋友圈

基于朋友圈的设计还原的完整站点：
**Node + SQLite + Vue 3**，前台还原微信朋友圈的信息流体验，后台提供内容与站点管理。

- 前台：`/`
- 后台：`/admin`（默认 `admin / admin123456`）

---

## 一、技术栈

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 前端 | Vue 3 + Vue Router + Vite | 单页应用，无 UI 框架，样式按原主题手工还原 |
| 后端 | Node.js + Express | REST API，Session Token 鉴权 |
| 数据库 | SQLite（`node:sqlite` 内置模块） | 零原生依赖，无需 `better-sqlite3` 编译 |
| 上传 | multer | 图片 / 视频 / 音频，落盘到 `server/uploads` |
| 图标 | Remix Icon | 与原主题一致的 `ri-*` 图标 |

> **Node 版本要求：≥ 22.5**（`node:sqlite` 从 22.5 起提供）。当前项目在 Node 22.22 上验证通过。

---

## 二、快速开始

```bash
# 1) 安装依赖（前后端各一次）
npm run setup

# 2) 构建前端
npm run build

# 3) 启动（默认 http://localhost:3000）
npm start
```

开发模式（前端 5173 热更新 + 后端 3000，通过 Vite 代理）：

```bash
npm run dev
```

首次启动会自动建库并写入**最少量**的初始数据：**1 个管理员账号**、**1 条**示例动态、**1 条**示例评论、站点设置。
友情链接、点赞默认都**不预置**（前台会显示「还没有添加友链」），内容由站主自己添加。
数据库文件：`server/data/pyq.db`，上传文件：`server/uploads/`。

重置演示数据（**会清空全部内容，需输入 yes 确认**）：

```bash
npm run reset
```

### 初始账号

| 账号 | 密码 | 角色 |
| --- | --- | --- |
| admin | admin123456 | 管理员 |

> **只预置这一个账号**，不再附带其它演示用户（避免开源分发时别人用猜得到的弱密码登进来）。
> 首次登录后请立刻在后台「账号设置」里**修改密码和邮箱**——邮箱可以直接改，不需要动数据库。

## 三、功能清单

### 前台（还原原主题）

- **封面**：单图 / 多图轮播 / 视频背景（后台切换，视频自动静音循环）
- **资料区**：站点名压在封面上、圆角头像、个性签名
- **按时间筛选**：右上角日历按钮（不占首页版面），点开弹出月份列表（含每月条数），选完即筛；筛选中按钮带绿点标记，再选「全部时间」恢复，点空白 / Esc 关闭
- **动态流**
  - 置顶、广告标签；文字超 5 行折叠「全文 / 收起」
  - 单图自适应（竖图竖着、横图横着）、2/4 图两列、3 图以上九宫格
  - 视频动态、音乐卡片（点击即播）、定位、广告外链
  - 相对时间（刚刚 / N 分钟前 / N 小时前 / 日期）
  - 点赞（登录用户按账号、游客按 cookie 匿名点赞，都能取消）、点赞名单、评论数
    - 游客登记过昵称的，点赞列表里**显示昵称**；没登记的才合并成「访客 / 访客 ×N」
    - 登记之前点过的赞会在保存时一并回写昵称，不用取消重赞
  - 点击「…」滑出深色「详情 / 赞 / 评论」操作条（与原主题一致的交互）；「详情」进单条动态页，窄屏会自动收紧间距
  - 评论区：`昵称：内容`、楼中楼「A 回复 B：内容」、展开全部、删除自己的评论
  - 评论框：登录用户直接评；游客填「昵称 / 邮箱 / 网站」，记录上次昵称；表情面板分「Emoji」与后台配置的表情包分组，插到光标处
  - **信息登记**（右下角浮动按钮，背景音乐上方）：昵称\* / 邮箱\* / 网站，存本地后**评论框自动预填、点赞自动带昵称**；与评论框共用同一份数据（`localStorage.pyq_guest`），两边永远同步；已登记时图标点亮主题色
  - 评论表情包：点图即插入，输入框下方显示已插入的表情（点一下移除）；发送后直接渲染成图片、GIF 会动，一条评论最多 20 个表情，表情**不占** 1000 字额度
  - 评论内容安全：单条最多 **1000 字**（前后端都校验、按码点算，emoji 算 1 字）；入库前统一清洗（去 HTML 标签、解实体、去零宽字符），恶意代码（`<script>`、`onerror=`、`javascript:`、SQL 注入等）直接拒绝；昵称 / 邮箱 / 网站分别做长度、格式与协议校验，网址只允许 http/https
  - 动态流**滚动到底自动加载下一页**（`IntersectionObserver`，提前 300px 预取，一页没铺满屏幕会自动补到铺满）；不支持的浏览器保留「加载更多」点击兜底
- **友站动态**（首页底部）：订阅好友站点的最新动态，只显示摘要卡片，点「查看原文」跳回对方站点阅读
  - 后台填「站点地址 + 授权 Key」添加，**添加前先试拉一次**，拉不通就不让保存
  - 每张卡片：站点头像 + 站点名 + 「好友」标签 + 相对时间 + 140 字摘要 + 最多 3 张缩略图；整卡外链新窗口打开，本站不留全文
  - 点「好友」标签可以「不看」这个站：二次确认后整块隐藏，cookie 记 7 天；隐藏后原位留一条「已隐藏好友内容 · 恢复显示」的淡提示，随时点得回来
  - 只拉对方最近 20 条，默认显示 6 条可展开；**对方站点挂了整块不显示**，不留报错也不留空壳
- **动态详情页**：全文 + 图片灯箱 + 完整评论树 + 回复 + 删除
- **个人主页**：头像、简介、动态数、被赞数、该用户动态流
- **发布页**：文字、最多 9 图、视频、音乐（上传或直链）、**网页卡片**（粘贴链接自动抓图标 / 标题 / 描述）、位置（默认按 IP 自动带出到市级，可手动改写 / 清空 / 重新定位）、广告外链（管理员）、置顶 / 广告标记（管理员）、表情；**图片可直接 Ctrl+V 粘贴上传**（截图、复制的图片都行，连粘多张累加，超过 9 张按剩余额度截断）
- **搜索弹窗**：实时搜索动态内容与昵称，关键词高亮
- **友情链接弹窗**
- **登录 / 注册 / 退出**：注册开关、密码校验、登录态持久化
- **夜间模式**：19:00–07:00 自动切换 + 手动切换（localStorage 记忆，首屏无闪烁）
- **图片灯箱**：左右切换、键盘 ← → / Esc、序号
- **悬浮音乐播放器**：可拖拽、封面旋转、进度条、暂停 / 关闭；默认不出现，点右侧悬浮菜单的音乐按钮才唤起并开始播放，再点暂停，关掉即收起
- **返回顶部 / 滚动毛玻璃顶栏 / 移动端适配**

### 后台（`/admin`）

- **仪表盘**：动态、评论、点赞、用户四项统计 + 今日增量 + 14 天发布趋势 + 最近动态 / 评论 + 快捷操作
- **动态管理**：搜索、状态筛选、分页、查看 / 编辑 / 置顶 / 删除
- **评论管理**：状态分页签（全部 / 已通过 / 待审核 / 已隐藏）、AI 状态筛选、搜索、通过、隐藏、重新送审、删除、管理员回复；每条评论同时显示「内容状态 + AI 状态」两个徽章，违规的会带红色 AI 理由
- **AI 审核**（站点设置内）：兼容 OpenAI Chat Completions 协议，填接口地址 / API Key / 模型 ID 即可接入官方或中转站；可设间隔、每轮条数（上限 10）、AI 通过后是否自动放行待审核评论，支持「测试连接」「立即审核」与屏蔽词
- **表情包**：分组增删改（名称 / 排序 / 前台显隐）+ 组内上传表情（PNG / JPG / **GIF** / WebP，单张 ≤4MB，一次最多 30 张，支持点击选择或拖拽），同一张图重复上传自动跳过，删除表情 / 分组时同步清理文件；前台只显示「显示中」且非空的分组
  - **每个表情可单独改名**（上传后点表情左上角的笔，或双击图片）：名字用作前台悬停提示与图片 alt；没改过就沿用上传时的文件名
- **媒体资源**：扫一遍 `uploads` 目录，把上传过的图片 / 视频 / 音频都列出来（缩略图、大小、上传时间、所在目录），支持按类型、关键词、是否被使用筛选和分页
  - 每个文件都标了「被引用几处」，点开预览能看到具体是**哪条动态 / 站点头像 / 封面 / 表情包**在用它，可直接跳过去
  - 提供「复制地址」；删除前二次确认，**正在被使用的文件会拒绝删除**（避免前台破图），只允许清理真正没人引用的残留文件
- **用户管理**：搜索、新建、编辑（昵称 / 邮箱 / 头像 / 简介 / 角色 / 状态 / 重置密码）、禁用、删除
- **友情链接**：增删改、排序、显示 / 隐藏
- **友站联动**：本站对外开关 + 授权 Key（可复制 / 重置，重置后旧 Key 立即失效，界面直接给出要发给对方的接口地址）；添加订阅的友站（地址 + Key，**先试拉预览再保存**）、启用 / 停用、手动刷新、删除；列表显示每站的同步状态、条数与最近同步时间
- **站点设置**：站点名、签名、头像、版权、每页条数、主题色、封面（单图 / 轮播 / 视频）、注册开关、评论审核、夜间自动切换、背景音乐列表（上传或直链）；浏览器标签页图标（favicon）自动跟随站点头像，改完头像无需另外传图标
- **网站 TDK**（站点设置内）：标题 / 描述 / 关键词三项可后台配置，另带搜索结果预览；**由服务端直接注入首屏 HTML**，不依赖 JS 执行，爬虫抓到的就是后台填的值；同时输出 `og:title` / `og:description` / `og:image` / `og:url`，微信、微博等分享卡片也能取到正确信息
- **账号设置**：改资料、改密码、**登录安全**（近 24 小时成功 / 失败次数、当前被锁的 IP 与账号、解除锁定、最近 40 条登录尝试，含 IP / 账号 / 失败原因 / UA）

## 四、目录结构

```
朋友圈/
├── package.json              # 根脚本：setup / dev / build / start / reset
├── scripts/dev.mjs           # 同时拉起 vite 与 express
├── server/
│   ├── data/pyq.db           # SQLite 数据库（自动创建）
│   ├── uploads/              # 上传文件（seed 目录是演示素材）
│   └── src/
│       ├── index.js          # Express 入口 + 静态托管 + SPA 回退
│       ├── seo.js            # 首屏 TDK 注入：title / description / keywords / Open Graph
│       ├── db.js             # 建表、密码哈希、设置读写
│       ├── guard.js          # 内容安全：文本清洗、恶意代码识别、昵称/邮箱/网址校验
│       ├── ai-review.js      # AI 评论审核：OpenAI 兼容调用 + 定时任务
│       ├── geo.js            # IP 归属地（市级）：三级数据源降级 + 内存缓存
│       ├── security.js       # 登录防爆破：三层失败计数、锁定、登录尝试日志
│       ├── auth.js           # Session Token / Cookie / 权限中间件
│       ├── federation.js     # 友站联动：对外 feed、内存缓存、定时刷新
│       ├── seed.js           # 演示数据
│       ├── reset.js          # 重置数据库
│       └── routes/
│           ├── auth.js       # 注册 / 登录 / 退出 / 我的资料 / 改密码
│           ├── posts.js      # 动态列表、详情、增删改、点赞、评论
│           ├── comments.js   # 删除自己的评论
│           ├── public.js     # 站点设置、友链、搜索、作者资料
│           ├── upload.js     # 文件上传
│           ├── stickers.js   # 表情包：分组、上传（GIF）、去重、改名、删除
│           ├── media.js      # 媒体资源：扫描 uploads、引用关系、删除保护
│           ├── federation.js # 友站联动：feed 接口 + 后台订阅配置
│           └── admin.js      # 后台：统计 / 动态 / 评论 / 用户 / 友链 / 设置
└── client/
    ├── index.html
    ├── vite.config.js
    └── src/
        ├── main.js / router.js / api.js / store.js / utils.js
        ├── styles/main.css   # 前台样式（含夜间模式变量）
        ├── styles/admin.css  # 后台样式
        ├── components/       # TopBar / Cover / PostCard / CommentList / FriendFeed（友站动态）/ GuestProfileModal / 弹窗 / 播放器 …
        └── views/            # Home / PostDetail / Author / Write / admin/*
```
